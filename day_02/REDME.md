
# Tip Calculator 🖩

A simple Python program to help you calculate how much each person should pay when splitting a bill, including a tip.

## How it Works
- The program asks for:
  - The total bill amount
  - The tip percentage you would like to give (e.g., 10, 12, or 15%)
  - The number of people splitting the bill
- It then calculates the total amount each person should pay, including the tip.

## Example
```bash
Welcome to the tip calculator!
What percentage tip would you like to give? 10 12 15: 12
How many people to split the bill? 5
Each person should pay: $33.60
```

## How to Run
1. Make sure you have Python installed.

2. Save the code into a file, for example `tip_calculator.py`.

3. Open your terminal or command prompt.

4. Navigate to the folder where `tip_calculator.py` is located.

5. Run it with:
```bash
python tip_calculator.py
```
