# Treasure Island 🏴‍☠️

A simple text-based Python adventure game where your mission is to find the hidden treasure without falling into traps!

## How it Works
- The program asks for:
  - A direction at a crossroad ("left" or "right").
  - A decision at a lake ("wait" for a boat or "swim" across).
  - A door color to choose on the island ("red", "yellow", or "blue").
- Your choices determine whether you win the game or face a Game Over!

## How to Run
1. Make sure you have Python installed.

2. Save the code into a file, for example `treasure_island.py`.

3. Open your terminal or command prompt.

4. Navigate to the folder where `treasure_island.py` is located.

5. Run it with:
```bash
python treasure_island.py
```
