# Rock Paper Scissors ✊🖐✌️

A simple Python game where you play Rock, Paper, Scissors against the computer!

## How it Works
- The program asks you to choose:
  - **0** for Rock ✊
  - **1** for Paper 🖐
  - **2** for Scissors ✌️
- The computer randomly makes its own choice.
- The winner is decided based on traditional Rock-Paper-Scissors rules.

## How to Run
1. Make sure you have Python installed.

2. Save the code into a file, for example `rock_paper_scissors.py`.

3. Open your terminal or command prompt.

4. Navigate to the folder where `rock_paper_scissors.py is located.

5. Run it with:
```bash
python rock_paper_scissors.py
```
